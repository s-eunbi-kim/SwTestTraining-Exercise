# RPAS 요구사항 명세서

## 시스템 개요

RPAS(Remote Parking Assist System)는 스마트키를 이용하여 차량 외부에서 원격으로 시동을 걸고, 주차를 수행할 수 있는 시스템이다.

---

## 기능 1. 원격 시동 (Remote Start)

### RS-001. 원격 시동 사전조건

원격 시동을 사용하려면 다음 조건을 **모두** 만족해야 한다.

| 조건 ID | 조건 | 비고 |
|---|---|---|
| RS-001-a | 스마트키와 차량 간의 거리가 10m 이하 | 허용 오차 ±0.5% |
| RS-001-b | 시동이 꺼진 상태 (엔진 OFF) | |
| RS-001-c | 기어가 P (주차) 위치 | |
| RS-001-d | 스마트키 배터리 잔량이 5% 이상 | |

### RS-002. 원격 시동 활성화

사전조건(RS-001)을 만족한 상태에서:

1. 스마트키의 **도어 잠금 버튼**을 눌러 도어를 잠근다.
2. 도어 잠금 후 **4초 이내**에 **원격 시동 버튼**을 **2초 이상** 누르면 원격 시동이 활성화된다.

### RS-003. 비상등 점멸

원격 시동 또는 스마트키 조작 시 비상등을 점멸하여 상태를 표시한다.

| 동작 | 비상등 점멸 횟수 | 조건 |
|---|---|---|
| 도어 잠금 | 1회 | 도어 해제 상태에서 도어잠금 버튼 클릭 |
| 도어 잠금 해제 | 2회 | 도어 잠금 상태에서 도어잠금 버튼 클릭 |
| 원격 시동 성공 | 3회 | 원격 시동 버튼을 2초 이상 눌러 시동이 걸렸을 경우 |

### RS-004. 원격 시동 실패 처리

원격 시동이 실패할 경우:
- 비상등이 **점멸하지 않는다**.
- **경고음**을 울린다.

### RS-005. 원격 시동 거리 경계

- 스마트키와 차량 간의 거리가 정확히 10m일 때 원격 시동이 **가능**하다.
- 거리가 10.05m(10m + 0.5% 허용 오차)를 **초과**하면 원격 시동이 **불가능**하다.
- 거리가 10.05m 이하이면 원격 시동이 **가능**하다.

## 기능 2. RSPA 활성화 (원격 스마트 주차)

### RSPA-001. RSPA 활성화 사전조건

RSPA를 활성화하려면 다음 조건을 **모두** 만족해야 한다.

| 조건 ID | 조건 |
|---|---|
| RSPA-001-a | 시동이 걸린 상태에서 차량 속도 5km/h 이상으로 주행한 이력이 있음 |
| RSPA-001-b | 현재 차량 속도 == 0km/h (정차 상태) |
| RSPA-001-c | 기어가 "N" (중립) 위치 |
| RSPA-001-d | 주차/뷰 버튼을 3초 이상 누름 |

### RSPA 파라미터 정의

| 파라미터 | 값 | 비고 |
|---|---|---|
| 차량속도 (km/h) | 0, 3, 5, 10 | 0: 정차, 5: 주행이력 판정 기준 |
| 기어 | P, R, N, D | N: RSPA 활성화 조건 |
| 버튼 누름 시간 (초) | 0, 2, 3, 5 | 3: 활성화 경계값 |
| 주행이력 | 없음, 있음 | 5km/h 이상 주행 여부 |

### RSPA-002. RSPA 활성화 실패

RSPA-001의 조건 중 하나라도 만족하지 않으면 RSPA가 활성화되지 않는다.

## 과거 오류 DB

### 초음파 센서 관련

아래 상황에서 물체를 부정확하게 감지할 수 있다.

**주변 환경:**
- 온도: 기준값에서 ±3도 이내로 급격하게 변화할 경우 (-10도 이내에서 3도 변화) 오차 범위 조정 필요
- 풍속: 풍속이 20km/h 이상일 경우 초음파 센서 값 변동, 오차 범위 30cm 이내
- 날씨: 비, 눈 등 악천후

**물체 모양:**
- 뾰족한 물체나 로프 등과 같이 가는 물체 (예: 소화전)
- 사각 기둥의 모서리 등과 같이 폭이 좁은 물체
- 직경 14cm, 길이 100cm 미만의 작은 물체
- 면이나 스펀지, 눈 등 초음파를 흡수하기 쉬운 물체
- 초음파 센서로부터 10cm 이내에 위치한 물체

### 광각 카메라 관련

아래 경우 주차선이나 물체를 부정확하게 감지할 수 있다.

- 낮은 물체(연석 등), 뾰족한 물체, 가는 물체(로프 등)
- 물체가 차량과 30cm 이내로 가까이 있거나, 8m 이상 위치한 경우
- 노면 상태(자갈, 흙 등)에 따라 빛 반사가 일어나는 경우
